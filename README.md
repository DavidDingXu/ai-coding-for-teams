个人能用 AI 写出代码，团队为什么仍然难以交付？这门课程从这个问题出发，梳理规则、上下文、任务、验证和协作之间的关系。

适合技术负责人、研发效能团队，以及正在把个人经验推广到团队的开发者。14 篇文章已全部公开，按顺序阅读即可理解整套方法。

你会沿着一条团队交付链往下读：

**共同规则 → 需求拆分 → 有界上下文 → 小步交付 → 验证与接管 → 经验复用**

刚开始建设团队流程，可以先通读；已经遇到具体问题，可以从下面的文章直接进入。
