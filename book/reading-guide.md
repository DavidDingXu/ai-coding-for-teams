# 如何阅读本书

本书适合技术负责人、研发效能团队，以及已经有个人 AI Coding 经验、正在开展团队协作的开发者。阅读不要求安装特定工具，也不要求先实现一套完整的 Agent 平台。

第一次阅读建议按五篇顺序推进。若正在准备试点，可先读第 12 章的最小落地包，再回查规则、上下文和验证治理。书中保留原课程编号：00 为序章，01—12 为正文，13 为结语；配套网页和仓库沿用同样的编号。

读到目录模板时，先判断它保存了什么事实、谁负责更新、其他人如何接管，再决定是否采用相同文件名。流程图在书中以静态图呈现，可以离线阅读；目录和命令示例仍保留原始文本。

每篇扉页给出阅读重点。章内图表使用“章号-序号”编号；章末配套资源供需要进一步查阅时使用。网页链接和配套文件不是理解正文的前置条件。

PDF 使用 A4 版式，较密的宽图独立横排，适合固定版式阅读与打印，EPUB 可随设备调整字号。两种版本均包含完整正文和配图，不依赖联网加载图片；外部文档、源码与问题反馈需要联网访问。
